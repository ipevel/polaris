## 下一版（1.12.1 之后的第一版）必须回归

- [ ] **[未取证] zh-CN Windows**：更新页「检查更新 → 下载 → 校验 → 安装」全链路 ——
      ① 摘要取不到时，更新弹窗与「设置 → 关于」都显示「本次未做包校验（取不到发布侧摘要 ≠ 包有问题，但本次没有校验）」；
      ② 连续 3 次取不到时换成醒目说法「连续 N 次未做包校验…请留意下载来源」；
      ③ 安装后启动时内核 `resources/core/mihomo.exe` 定点核对通过（或如实显示「内核启动校验未执行」）。
- [ ] **[未取证] en-US Windows**：同上，重点是 `Expand-Archive` / bsdtar 对 **UTF-8 中文条目名**的解码
      （发布侧已改为直接读 zip 条目校验；客户端解压路径要真机确认不误判「清单缺少条目」）。
- [ ] **[未取证] 摘要连续取不到达 N=3**：断开网络连查 3 次，确认界面从「本次未做包校验」升级为「连续 3 次…」，
