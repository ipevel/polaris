### 安卓

- **节点页的分流组名与设置页对齐**：「Ⓜ️ 微软」组在设置页早已显示为「Ⓜ️ 微软云盘」，本版把节点页的分流组卡也按新名显示（此前它会直接显示随包内核里的旧名）。
- 你原来对这些分组的**开关与拖动顺序完全不受影响**（内部键与持久化格式未变）。

### Windows

- **与内置组同名的自定义分流组不再被静默删除**：自动检查不再把这类分组从配置里删掉并写盘，而是把它**列在「设置 → 分流规则」页里**（并可从「导出本地分流配置」带走）。
  ⚠️ 在 1.12.0 / 1.12.1 期间**已经被删掉的条目无法找回**，只能手工重建。
- **更新包新增完整性校验**：下载完成后按发布侧公布的摘要**逐字节核对**，不符就删除该包并明确报错；**启动前**还会定点核对内核可执行文件，避免"装了一半也能启动"的假成功。
- **版本号口径修正**：产物里的版本号现在与仓库声明值一致（此前发版时会被现算值覆盖，导致「设置 → 关于」显示的版本号与实际不一致）。
- 本版还修了发版与 CI 的稳定性问题（孤儿 tag、发版版本号口径、CI 重试），**对日常使用无可见影响**。
- **本版未带**（顺延下一版）：更新失败的可观测改进、启动自检、安卓端 v3 签名 / 分应用选择页 / 深链导入 / 快捷磁贴。
- **更新器手工恢复口径**：如果更新后应用打不开、安装目录里只剩下 `Polaris.exe.old`，请把它重命名回 `Polaris.exe` 再双击启动，然后在「设置 → 检查更新」重新更新一次；你原来的配置和数据（`data\` 目录）不受影响。
- 验证边界：本版改动经过 CI 与脚本级验证（含失败注入、回滚断言、清单正/负例、幂等与断言用例），**未做真机端到端更新验证**。
