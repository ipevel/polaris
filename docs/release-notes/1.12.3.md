### Windows

- 开着代理时，应用内更新不再直连 GitHub——下载走本机代理，更快也更不容易失败。（#58）
- 「检查更新」失败不再假装成功：按原因分档提示，并写入日志。（#48）
- 更新过程的失败可查：能看到本轮意图、进程存活与 helper 输出，下次启动还会提示「上次没更新完」。（#47）
- 启动自检找残留内核：只认命令行里带我们自己数据目录的 mihomo 进程。（#50）
