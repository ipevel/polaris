### 安卓

- 修复「本地分流配置的自动检查」会**静默删除**自定义分流组的问题：检查改为**只读不回写**，被暂时隐藏的条目会**列在「设置 → 分流规则」页里**（不再删掉后无痕）；该页还新增「**导出本地分流配置**」入口。
- 说明：1.12.0 及更早版本里，与内置组同名的自定义分流组会在打开「设置 → 分流规则」时被删除并写盘，**已经被删掉的无法找回**，只能**手工重建**；本版起的导出只能保护**尚未被清掉**的条目，不能用来恢复已删内容。

### Windows

- 更新器改为**从新包运行 + 原子提交 + 全量备份回滚**：更新过程中安装目录**始终保留可启动的程序**；任何一步失败都会**自动回滚，并把失败原因显示出来**（不再静默失败）。
- 更新包新增**包内清单校验**：缺清单或哈希不符一律**拒绝安装**，不会装到一半。
- 版本比较修正：暂存包**旧于当前版本时不再提示安装**，避免降级重装。
- **本版更新器只保护由 1.12.1 发起的更新**；从 1.12.0 及更早版本升级时，执行安装的仍然是旧版更新器。
- **如果更新后应用打不开、安装目录里只剩下 `Polaris.exe.old`**：请把它重命名回 `Polaris.exe`，再双击启动；启动后在「设置 → 检查更新」重新更新一次。你原来的配置和数据（`data\` 目录）不受影响。
- 本版**未带**：Windows 自定义分流组的隐藏清单修复、分流组名显示对齐——顺延下一版。
- 验证边界：本版更新链改动经过 CI 与脚本级验证（含失败注入、回滚断言、清单正/负例），**未做真机端到端更新验证**。
