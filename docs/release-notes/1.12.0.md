### 安卓

- 修复「全部测速 / 单组测速」按钮在测速被取消或中途跳出后**永久置灰**的问题，现在一定会恢复可用。
- 更新包下载完成后若无法拉起系统安装界面，会**清理已下载的安装包并明确提示失败**，不再留下装不上的包。
- 修复自定义分流组连续增删改时可能**丢改动 / 串状态**的问题（写入加锁 + 保存中禁止再点）。
- 分流组改名：「Ⓜ️ 微软」→「Ⓜ️ 微软云盘」（原名实际只覆盖云盘 + 登录 + 系统更新 + Azure，改名更贴切）。**你原来对这一组的开关与拖动顺序会自动带过去**。
- 内核就绪等待与配置装载的并发路径加固，降低启动 / 切换订阅时的卡顿与异常风险。

### Windows

- 托盘：菜单项签名去重、生命周期收口；**主窗口全部关闭后托盘常驻恢复正常**。
- 启动自愈：程序缺失的 exe 会自动补齐，并保护「清理残留改名文件」不误删正在使用的文件。
- 更新下载地址**只放行 http(s)**，并在进入更新目录之前完成校验。
- 面板客户端的时间戳按值域显示为分 / 秒 / 毫秒，不再一律当毫秒。
- 版本比较改为严格按 SemVer：预发布版本、段数不一致、非法输入都能正确处理；**远端版本为空或非法时不再误亮更新红点**。
- 分流组改名：「Ⓜ️ 微软」→「Ⓜ️ 微软云盘」（与安卓端一致，开关与顺序同样自动带过去）。
